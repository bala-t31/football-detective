      Install in a minute

      Football Detective is installed straight from this site, not the Play Store, so Android asks you to allow it once.

      1. Download the app

        Tap Download for Android on your phone. The file is called football-detective.apk.

      2. Open the file

        Open it from your notifications or the Downloads folder.

      3. Allow this install

        If Android says it can't install unknown apps, tap Settings and turn on “Allow from this source” for your browser, then go back.

      4. Install and play

        Tap Install, then Open. To update later, download the new version and install it over the old one. Your progress stays.

      Questions

      Anything else? Ask on Instagram.

      Is it free?

      Yes. No ads, no in-app purchases and no account to create.

      Is it hard?

      It doesn't have to be. The daily mystery only uses household names, the first hint always says what the player won, and practice lets you pick your level. If you are completely stuck, you can reveal the player for 150 XP.

      Is there an iPhone version?

      Not yet. Football Detective is Android only for now.

      Why does Android warn me before installing?

      Android shows that warning for any app installed outside the Play Store. The app asks for no special permissions, and its full source code is public on GitHub.

      Does it need the internet?

      No. Every player and clue is inside the app, so it works offline. Your progress is saved on your phone.

      How do I update?

      Download the latest version from this page and install it over the old one. Your streak, XP and trophies are kept.

      Where do the player facts come from?

      Every clue is written by hand from public records. If you spot a wrong fact or want a player added, send a message on Instagram and it will be fixed.
